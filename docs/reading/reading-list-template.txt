>> Before you hand it over, check the seven things no search finds for you:
>>   1. A decision this leg needs that nothing near the leg cites. Read each done-when item and
>>      ask what it silently depends on.
>>   2. A decision named by a phrase instead of by its ID. Search for the done-when's own words.
>>   3. What to skip. A citation means relevant, never necessary: cut what an earlier leg closed.
>>   4. What the plan left undecided. Name it under WHAT THIS LIST CANNOT SEE, so the session
>>      decides it on purpose.
>>   5. A file the leg deletes or replaces. Read that file; nothing cites a file on its way out.
>>   6. A spec that is a picture. A mockup or diagram linked from a doc is not a citation.
>>   7. Seams: files this leg must not open. The plan states them in prose, away from the paths,
>>      and the largest file in the repo is usually the one that needs naming.
