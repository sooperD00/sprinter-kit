# Drafts

Half-built work for an item that is filed but not done: a draft record, prompt, plan or script.

- Name a draft for its item: `<item-id>-<short-name>.<ext>`, such as `s-2f14eb-hooks-design.md`.
- Link the draft from its item with a `**Drafts:**` line, so the item says the draft exists.
- Keep a raw note's words. Give it a title, one line naming its item and where it came from,
  and the note itself in a `text` fence, so it reads exactly as written.
- No session reads a draft unless its prompt or reading list names the file. A draft is not a
  rule, and nothing cites one as a reason.
- Delete the draft when its item lands. git keeps it.
- This repo is public, so a draft is public the moment it's pushed.

This folder pilots `[s-db928b]`, which turns it into a template every project gets.
