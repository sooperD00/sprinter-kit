# Architecture Decision Records

The kit's own decisions. One record per file, `adr-<NNN>-<short-name>.md`. Numbers are
identity: they are assigned once, never reused, and never renumbered, so anything may cite a
record by its ID.

**Numbering.** 001–009 belong to the prompts. ADR-00N holds the reasoning for
`prompts/promptN-*.md`, so the records keep the prompts' order and remind you of the flow when
you pick one. A number whose prompt has no record yet is spoken for. Other records start at 010.

Start a new record by copying [the ADR template](../../templates/docs/decisions/adr-000-adr-template.md),
the same one projects get.
